# 2.2 (2026-11-26)

- **7z-Encryptor 1.2:** Show in folder and Send by email (Send to > Mail recipient with a Windows Share fallback, Windows Share, or a chosen mail program), and remembered folders and choices. See [7z-Encryptor-1.2.md](7z-Encryptor-1.2.md).
