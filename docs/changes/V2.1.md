# 2.1 (2026-11-26)

**WinFixKit gets the Automation and Registry changes tabs, and the WinFixKit beta is retired.** `tools/WinFixKit.ps1` is now the former beta `WinFixKit-beta-automation.ps1` (beta-automation 3), which was WinFixKit 1.9 / 2.0 plus two tabs. The separate beta script, its launcher and its zip are gone; there is one WinFixKit again, started with `Launch-WinFixKit.bat` as before.

## In WinFixKit

- **Automation (beta):** a queue of up to 10 of WinFixKit's status checks and fixes, run one after another, each in its own window with a pass / fail result, a final summary and an HTML report. Needs administrator rights and a running Windows (not WinPE). Notes: [beta-automation 1](WinFixKit-1.9-beta-automation.1.md), [2](WinFixKit-1.9-beta-automation.2.md).
- **Registry changes (beta):** registry keys changed since a date, compared with a shadow copy / restore point, WinFixKit's own registry backups, a Windows ISO / install.wim or a built-in list of 71 Windows defaults; revert only the values you tick, each key backed up as a `.reg` file first. Scanning changes nothing. Notes: [beta-automation 3](WinFixKit-1.9-beta-automation.3.md).
- Both tabs still say **(beta)** on the tab and in the line at the top of the tab, because they are newer than the rest of WinFixKit. The window title, the version line and the message boxes no longer say beta.
- Every other tab is the same as in 2.0, including the 2.0 `[ ]` folder fixes (they were already in the beta) and the empty Recycle Bin fix from beta-automation 1.
- WinFixKit keeps its data in `Desktop\WinFixKit` as before, plus `Task-Results` for Automation.

## Also

- Version lines: WinFixKit and `Launch-WinFixKit.bat` say `Version 2.1`. The other tools are unchanged and still say 2.0 (Backup Script Builder 1.5, 7z-Encryptor 1.1); the release zips are all named v2.1.
- `build/Port-AutomationToWinFixKit.ps1`, `tests/WinFixKitAutomation.Tests.ps1` and `tests/Run-WinFixKitAutomation.ps1` now work on `tools/WinFixKit.ps1`. The rule stays: Automation is changed in WinSuperTool first, then ported (see CONTRIBUTING.md).
- The bug and discussion forms no longer list the WinFixKit beta.

## How it was checked

No new testing was done for 2.1: the beta-automation 1 to 3 results stand (66 Automation tasks run for real as administrator, twice; Registry changes unit tests and window checks). For 2.1, the Pester unit tests were run on the promoted file, including the checks that the Automation port still matches WinSuperTool.
