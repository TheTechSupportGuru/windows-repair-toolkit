## New: HTML Automation report

The new Automation-tab option **"Save an HTML report and open it at the end"** is on by default. When the queue finishes, one self-contained page opens in your browser:

1. **At the top, the overall result in a coloured banner:**
   - green: ALL TASKS PASSED;
   - orange: all ran, but some results need attention;
   - red: N FAILED.

   Below the banner: the PC, start and finish times, the counts, and whether **a restart is needed**.
2. **A summary table**, one row per task:
   - number, task, a coloured **PASSED / FAILED / NOT RUN / Skipped** badge, the result (for example "CORRUPTION DETECTED - FIX WORKED") and the run time;
   - rows are colour-coded green / orange / red / grey;
   - a repair added automatically shows why ("added because DISM found repairable corruption").
3. **Details** for every task:
   - the tool's own words (quoted);
   - the next step, the command, the run time, the exit code (also in hex), the output file;
   - the **full output**, collapsible.

The page uses no scripts and no internet, and prints cleanly (the full outputs are left out of the print). It is saved next to the text summary in `WinSuperTool-Data\Task-Results`. **Open last HTML report** opens it again later.

## Also in beta 3

- **Scaling and resizing**, as in 1.8.1. In addition:
  - the Automation queue and the task list grow with the window;
  - the System Info and Automation windows scale;
  - the queue's columns widen with the display scaling.
- **Splash screen** while it loads.
- **No-AI edition** of the beta: tabs 1-9, without AI Analyze.
- The task-window watcher (Recovery summaries and Automation) now has its own timer handler, so the no-AI edition keeps it.
