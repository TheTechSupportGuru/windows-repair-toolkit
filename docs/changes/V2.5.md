# 2.5 (2026-11-26)

- **Backup Script Builder 1.8** ([notes](BackupScriptBuilder-1.8.md)): Ultra compression is 7-Zip only. With a zip made by Windows (built in) it is greyed out as "Ultra (7-Zip only)", so backing up now and the saved script make the same zip on Windows 10, 11 and PE.
- **7-Zip found in Windows PE** (Backup Script Builder 1.8, [7z-Encryptor 1.5](7z-Encryptor-1.5.md)): In Windows PE (Hiren's BootCD PE 10 / 11 and others) the tools also look for 7-Zip on the X: and Y: drives, up to 3 folders deep, and in the PATH.
- **Remember settings keeps zip or 7z:** 7z-Encryptor 1.5 remembers 7z or zip; Backup Script Builder 1.8 remembers the Manual Backup type (folder, zip or 7z) and who makes the zip. Without 7-Zip it falls back to a Windows zip but keeps the 7-Zip choice for the next PC.
- **Drag and drop from Explorer:** onto Backup Script Builder's Manual Backup list and 7z-Encryptor's list (files and folders), and onto Backup Script Builder's Destination folder, Log folder and Save to boxes (a folder, or a file's folder).
- **Test Center 1.0** ([notes](TestCenter-1.0.md)): out of beta, and its Backup Script Builder and 7z-Encryptor tests cover all of the above.
- The bug report and Q&A forms list 2.5.
- The other tools are the same as in 2.4; the release zips are named v2.5.
