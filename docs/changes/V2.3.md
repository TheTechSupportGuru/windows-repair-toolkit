# 2.3 (2026-11-26)

- **Remember settings is a choice now, off at first**, in 7z-Encryptor 1.3 ([notes](7z-Encryptor-1.3.md)) and Backup Script Builder 1.7 ([notes](BackupScriptBuilder-1.7.md)). Nothing is written to the tool's folder until the box is ticked, and unticking deletes the settings file.
- **A damaged settings file means no memory**: bad JSON, wrong values, or a 2.2 file without the new `Remember` flag is ignored, and the tool starts as if it had no settings. So settings saved by 2.2 are not used. Tick the box once to keep them again.
- The other tools are the same as in 2.2; the release zips are named v2.3.
