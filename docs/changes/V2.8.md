# 2.8 (2026-11-27)

Drag and drop: every box that takes a file or folder name now also takes one dragged from Explorer.

- **WinSuperTool 2.1** (and the no-AI edition): the Collect Logs output folder (a dropped folder gets \logs, like Browse...) and the Run a script box (a dropped file).
- **WinFixKit 2.2:** Registry changes - the Windows ISO / image box (a dropped .iso, .wim or .esd is read like Browse...) and the folder the original keys are backed up to.
- **Backup Script Builder 2.0** ([notes](BackupScriptBuilder-2.0.md)): the Source folders list of the Build Script tab (folders, and files for Robocopy / Xcopy), the Schedule Task script box and the FreeFileSync.exe box.
- **7z-Encryptor 1.8** ([notes](7z-Encryptor-1.8.md)): the Save as box.
- The other tools have no file or folder boxes and are the same as in 2.7.

Tested on Windows 11: 571 / 571 Pester tests, 134 / 134 Backup Script Builder checks, 115 / 115 7z-Encryptor checks. The drops were tested by calling each box's drop code; not dragged by hand, and not run in Hiren's PE.
