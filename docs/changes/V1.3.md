Every changed file has a `# Version 1.3` (or `rem Version 1.3`) line at the top, and **all files are pure ASCII**. The scripts have no BOM, so Windows PowerShell 5.1 reads them as ANSI. Special characters are written in the code as `$([char]0x2019)`.

## Changes

| # | Sev | Script | Change |
|---|---|---|---|
| 7 | S3 | Collect-Logs | When another admin elevates, logs now go to the **logged-in user's** Desktop. It reads the raw `User Shell Folders\Desktop` value, so `%USERPROFILE%` no longer expands to the admin's profile. Same code as WinSuperTool. |
| 8 | S3 | WinSuperTool `Esc-Sq`, Monitor-Logs `Esc`, WinFixKit new `ConvertTo-SqEscaped` (used by `Start-InWindow`) | Typographic quotes `‘ ’ ‚ ‛` are doubled as well as `'`, so paths like `O’Brien` no longer break the code that runs in the spawned window. |
| 9 | S3 | WinSuperTool, ClaudeLogAnalyzer | QR pairing: at most **3 connections per timer tick** (it runs on the GUI thread), a 0.7 s read timeout instead of 1.5 s, and the QR code is cancelled after **40 connections** (logged as "another device on the network?"). A device on the LAN can no longer freeze the window. |
| 10 | S3 | WinSuperTool, WinRepairTool | `bcdboot /f` now follows the **PC's firmware** (new `Get-FirmwareType`: PEFirmwareType in WinPE, `%firmware_type%` in Windows). If the chosen partition doesn't match, you get a warning (No is the default). The boot-partition list no longer **auto-picks USB sticks** and marks them "(removable)". |
| 11 | S3 | WinFixKit | New `Test-BackupPending`: once a registry backup has been **restored**, the next fix takes a **fresh** backup, so the next restore returns to the value from just before that fix, not the very first one. Backups that haven't been restored, or can't be read, are never overwritten. |
| 12 | S4 | WinFixKit | An empty REG_MULTI_SZ is now backed up as an empty list and restored as an empty list. Old backups that stored it as `null` are restored correctly too. |
| 13 | S4 | WinSuperTool, WinRepairTool | Unattend: user names containing `%` (cmd would expand them in the FirstLogonCommand) or typographic apostrophes are rejected with a clear message. |
| 14 | S4 | WinSuperTool, WinRepairTool | `Invoke-Bcd` now backs up before **every** bcdedit verb except the read-only ones (`/enum /v /export /?`). |
| 15 | S4 | WinSuperTool, WinRepairTool | `bootrec /fixmbr` and `/fixboot` warn on UEFI PCs (No is the default) and point to bcdboot instead. |
| 16 | S3 | WinSuperTool, WinRepairTool | The Sysprep pre-flight BitLocker check uses WMI (`Win32_EncryptableVolume`, new `Get-BitLockerState`), which works in any language. If the state can't be read, it now says **WARN – could not check** instead of a false **OK**. |
| 17 | S3 | WinFixKit | The Registry Backups tab now shows a red **WARNING** naming any unreadable backup file, explains how to import its .reg export by hand, and writes it to the output log. |
| 18 | S4 | WinSuperTool | If the activity log file can't be written, a one-time warning appears in the on-screen log instead of losing the audit trail silently. (The `Save-Mounts` part was already fixed in V1.2.) |
| 19 | S4 | WinFixKit | The `Add-BottomButton` parameter is renamed `$Tip` → `$TipText`, so it no longer hides the global `$tip` ToolTip. Bottom-bar tooltips work and the 12 startup errors are gone. |
| 20 | S3 | Launch-WinFixKit.bat, Start-ClaudeLogAnalyzer.bat | Missing script → a console message and pause, exit code 1. Script fails to start (e.g. syntax error) → an **error message box** with the reason and line. Previously both failed silently. |
| 21 | S4 | WinFixKit | "Microsoft Account" status: a local account now shows "No UPN: this is a local account …" instead of a red `whoami` error. |
