# 2.6 (2026-11-26)

Fixes from the Hiren's BootCD PE 10 / 11 regression test of 2.5.

- **Backup Script Builder 1.9** ([notes](BackupScriptBuilder-1.9.md)): saved Windows-zip scripts use Windows' own .NET zip, no `tar.exe` (not in Windows PE); a saved `.bat` finds PowerShell 7 in Hiren's PE 10; the Schedule Task tab is greyed out in Windows PE.
- **7z-Encryptor 1.6** ([notes](7z-Encryptor-1.6.md)): 7-Zip's warnings (which file was skipped) are shown.
- **Every launcher** (`WinSuperTool.bat`, `WinSuperTool-NoAI.bat`, `Launch-WinFixKit.bat`, `Run-PS-As-Admin.bat`, `BackupScriptBuilder.bat`, `7z-Encryptor.bat`, `Start-TestCenter.bat`) uses PowerShell 7 (`pwsh.exe`, on the PATH or on X: / Y:) when there is no Windows PowerShell. Hiren's BootCD PE 10 has only PowerShell 7, so double-clicking a launcher there did nothing before.
- **Test Center 1.1** ([notes](TestCenter-1.1.md)): the WinPE test covers Backup Script Builder, 7z-Encryptor and Test Center, and the Test Center window test works in Windows PE.
- The .ps1 tools themselves are the same as in 2.5 apart from Backup Script Builder and 7z-Encryptor.
