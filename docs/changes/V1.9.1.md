# 1.9.1 (2026-11-22)

A packaging release: one release that holds everything, so the main toolkit is always at the top of the releases page. **The 8 v1.9 tools are unchanged** (their scripts still say `# Version 1.9`, and they are byte-identical to 1.9); only the zips are renamed `-v1.9.1`.

## New
- **Backup Script Builder 1.0** (`BackupScriptBuilder-v1.0.zip`): builds and schedules backup jobs for [FreeFileSync](https://freefilesync.org/), the free open source sync tool. See [BackupScriptBuilder-1.0.md](BackupScriptBuilder-1.0.md).

## Betas: only the newest one in this release
The separate pre-release entries were removed from the releases page (their tags stay). The 1.9.1 release holds only the **newest beta** of each tool in testing, so the main tools stay easy to find; the older betas are kept in the [v1.9 release](https://github.com/TheTechSupportGuru/windows-repair-toolkit/releases/tag/v1.9).
