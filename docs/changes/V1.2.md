# V1.2 changes (2026-11-19)

**Baseline:** V1.1. That's the original export: the top-level `WinFixKit.ps1` and `WinSuperTool.ps1`, plus `PS suite V1.1\`. Those originals are **unchanged** and stay where they are.
**What this iteration is:** fixes for the critical (S1) and major (S2) bugs found in testing. Details and evidence: [TEST-RESULTS-Phase0-1.md](../testing/TEST-RESULTS-Phase0-1.md)

## Files in this folder

| File | Status | Changes |
|---|---|---|
| `WinFixKit.ps1` | **changed** | #1 take-ownership check, #5 Service Killer |
| `WinSuperTool.ps1` | **changed** | #2 #3 mount memory, #4 BCD backup, #6 language-independent parsing |
| `WinRepairTool-startup.ps1` | **changed** | the same fixes as WinSuperTool (#2 #3 #4 #6) |
| `Launch-WinFixKit.bat`, `WinSuperTool.bat` | unchanged | copied here so this folder runs on its own (each .bat starts the .ps1 next to it) |

The standalone `Collect-Logs.ps1`, `Monitor-Logs.ps1` and `ClaudeLogAnalyzer.ps1` weren't touched. Use the V1.1 copies.

## Changes

| # | Sev | Script | Change |
|---|---|---|---|
| 1 | S1 | WinFixKit | New `Resolve-RealPath` follows junctions (e.g. `C:\Documents and Settings` → `C:\Users`) and expands 8.3 short names (`C:\PROGRA~1`). New `Test-ProtectedFolder` makes Take ownership + reset permissions refuse: drive roots; Windows, Program Files and ProgramData (and everything under them); `C:\Users`; the Default and Public profiles; any whole user profile; anything under AppData; and root system folders (Recovery, System Volume Information, `$Recycle.Bin`, EFI, Boot ...). The help text says ownership is not restored by the backup. |
| 2 | S2 | WinSuperTool, WinRepairTool | The mount memory now reloads every saved mount. Previously it lost all of them once 2 or more were saved. A failed save is now logged instead of ignored. |
| 3 | S2 | WinSuperTool, WinRepairTool | New `Test-MountStillOurs`: a remembered mount is used only if its drive letter still belongs to the same disk and partition. Otherwise it's dropped and logged, so "Unmount all" can't remove another drive's letter. |
| 4 | S2 | WinSuperTool, WinRepairTool | `Backup-Bcd` now reports success or failure. `Invoke-Bcd` refuses to change the BCD if the backup failed. The "BCD: back up store" tool shows an error when the backup fails. |
| 5 | S2 | WinFixKit | Service Killer: `mpssvc` (Windows Firewall) and `BFE` added to the blocked list. New `Test-RebootOnFailure` reads each service's recovery settings from the registry (works in any Windows language). The killer refuses any process that hosts a service set to restart the computer when it fails. |
| 6 | S2 | WinSuperTool, WinRepairTool | Boot entries are found by position and their `{…}` value instead of the English word "identifier". New `Get-DiskpartRows` reads diskpart tables by their `---` underline instead of the words "Disk" / "Partition". |
