# 2.4 (2026-11-26)

- **7z-Encryptor 1.4** ([notes](7z-Encryptor-1.4.md)):
  - **One window for both ways of starting.** Files or folders dropped on `7z-Encryptor.bat` open the normal window with them in the list, so the file picker and Save as with Browse... are there too. They are saved next to the first dropped item. The small drop window is gone, and dropping the script on its own launcher just starts it.
  - **Email with mailto:** type an address. Windows' own `mailto:` link opens a new email in your default mail program; drag in the file, which is selected in Explorer.
  - **Fixes:**
    - Names with `&` or `^` dropped on the launcher arrive whole (launcher 1.1).
    - The two passwords must match exactly, upper and lower case too.
    - Saving inside a folder that is being encrypted is refused.
    - `\\server\file.7z` is no longer taken as a full path.
  - **Every ? button** explains the 1.4 window, with new ones for Password and Remember settings.
- **Test Center 1.0 beta 4** ([notes](TestCenter-1.0-beta.4.md)): edge-case unit tests for 7z-Encryptor on its own tab, and the full 7z-Encryptor test covers the 1.4 window and launcher.
- The bug report and Q&A forms list 2.4.
- The other tools are the same as in 2.3; the release zips are named v2.4.
