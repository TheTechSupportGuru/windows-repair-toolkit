# V1.9 (2026-11-21): System Info, Automation (also in WinPE), task summaries, and windows that fit every screen

1.9 is the 1.9 beta (beta 1 to beta 5) made stable, together with the window work that was prepared as 1.8.4 and never released on its own. The beta is over: `beta/` holds no scripts any more.

| File | Status |
|---|---|
| `WinSuperTool.ps1`, `WinSuperTool.bat`, `WinSuperTool-NoAI.ps1`, `WinSuperTool-NoAI.bat` | **changed a lot**: the 1.9 beta, without BETA labels |
| `WinFixKit.ps1`, `WinRepairTool-startup.ps1`, `Collect-Logs.ps1`, `Monitor-Logs.ps1`, `ClaudeLogAnalyzer.ps1` | **changed**: shared window helpers, WinPE fixes |
| other launchers | unchanged |

## New in WinSuperTool

- **Recovery tab: pass / fail summaries.** When sfc, DISM, chkdsk, bcdboot, bootrec or a driver tool finishes, a window says whether it passed and what it found (for example NO CORRUPTION DETECTED, CORRUPTION DETECTED - FIX WORKED, FIX DID NOT WORK), quoting the tool's own words. Live log windows per task; scan-only tools (sfc /verifyonly, DISM check / scan health). Details: [beta 1](V1.9-beta.1.md).
- **System Info tab:** saved Wi-Fi networks and passwords, Windows version and product keys, every network connection, Bluetooth, video cards and **every display** (resolution, scaling, position), audio; 42 buttons for built-in Windows tools. Copy all / Save as... Details: [beta 2](V1.9-beta.2.md), [beta 5](V1.9-beta.5.md).
- **Automation tab:** a queue of up to 10 tasks (restore point, SFC, DISM, chkdsk, Windows Update, winget, Defender) with "repair only if needed", a pop-up per task on the tool's monitor, a final summary and an **HTML report** that also fits a phone screen. Presets. Details: [beta 2](V1.9-beta.2.md), [beta 3](V1.9-beta.3.md).
- **Automation in WinPE:** the queue works on the Target Windows while it is not running - SFC, DISM (check, scan, restore health, cleanup), chkdsk scan, and a WinPE-only **Check disk and REPAIR** (`chkdsk /f`). Tasks that need the running Windows are refused with the reason. Details: [beta 5](V1.9-beta.5.md).
