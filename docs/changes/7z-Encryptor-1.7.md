# 7z-Encryptor 1.7 (2026-11-27)

- **mailto: no longer closes the "pick an app" prompt.** With no default mail program set, Windows asks which app should open mailto: links. The tool used to open Explorer at once, which closed that prompt. It now waits until the prompt is gone (an app picked or the prompt closed, at most 10 minutes) and then selects the file in Explorer.
- **Change Default: mailto: / Email.** Next to Send by email. 'mailto:' opens Windows' own "pick an app" prompt for mailto: links (choose your mail program and Always; Settings > Default apps where that prompt is not available, a message in Windows PE). 'Email' picks the classic mail program that Attach (Send to) uses, from the ones installed (saved for your user only, no administrator needed). Both ask "Are you sure...?" first.
- **Clearer email choices.** The classic option is now called 'Attach (Send to)', so it is clear that this one attaches the file. The Windows Share option is gone (Attach still falls back to the Share window when there is no classic mail program; a remembered Share becomes Attach).
- **Choose program: with a list.** A quick search (registry and the usual folders, no disk scan) finds Outlook classic, Thunderbird, the new Outlook and every other mail program registered with Windows; pick one from the list or Other... to pick one yourself. The new Outlook cannot be given a file, so it opens with the file selected in Explorer to drag in.
- **mailto: works before anything is encrypted.** With mailto: picked, Send by email is on right away and just opens a new email to the address typed.
- **Save as: File or Folder: Named + Date.** 'File' saves to exactly the file named in the box. 'Folder: Named + Date' saves into the folder in the box, named after the text on the right plus the date and time to the minute (for example Encrypted-11-27-26--14-05.7z; a second one in the same minute gets (2)). Remembered with Remember settings.
- **A cleaner window.** Five numbered sections with a line between each and the same spacing everywhere; each ? sits right after its heading; Format choices share one line; the password boxes are wider and start right after their labels; Show in folder sits next to Encrypt; Send by email sits under Default...; no empty space at the bottom.
- **Simpler ? help.** Every ? opens its own window with short sections, each under a bold title, with a blank line between them.

Tested: `tests/Run-7zEncryptor.ps1` (114 passed: layout, Send without a file, Folder: Named + Date encrypted for real twice in one minute) and `tests/7zEncryptor.Tests.ps1` (auto name and free name edge cases, the mail program list and choice, finding mail programs, 64 passed).
