## Changes

| # | Sev | Action | Change |
|---|---|---|---|
| 22 | S3 | Test access to a PC / NAS | The `Open \\host : FAILED` line used `Test-Path "\\host"`, which is **always false for a bare server name**, so it reported FAILED even when SMB worked. It's replaced by **"Share list (net view \\host): OK / FAILED (exit code N)"**, judged by `net view`'s exit code (language-independent). Error lines from net view are shown as plain text, without PowerShell's `RemoteException` noise. |
| 23 | S4 | Rebuild search index | Deleted only `Windows.edb`. **Windows 11 22H2+ uses SQLite files:** `Windows.db`, `Windows-gather.db`, `Windows-usn.db`, plus `-wal`/`-shm`, confirmed on this VM. It now deletes all of these as well as `Windows.edb`, and leaves other files alone. The help text is updated. |
| 24 | S4 | Test access to a PC / NAS | For an IP address it showed "Name lookup: OK ()". It now says *"not needed (target is an IP address)"*, plus the reverse name if there is one. For a name, it lists **all** A/AAAA addresses, skipping a leading CNAME record. |
