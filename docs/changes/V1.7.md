# V1.7 changes (2026-11-19)

**Baseline:** [V1.6](V1.6.md).
**What this iteration is:** a logic and optimization pass over the two main tools, from the four parallel code reviews in [REVIEW-V1.6.md](../testing/REVIEW-V1.6.md). It also includes fixes for three problems found by actually running the windowed fixes (Phase 3, part 4). Every finding was checked in the code before it was fixed. Findings I didn't fix are listed at the end with the reason.

## WinFixKit

| # | Sev | Change |
|---|---|---|
| K1 | S2 | **"Enable Network Discovery + File/Printer Sharing" no longer rewrites rule profiles.** It used `Set-NetFirewallRule -Profile 'Private,Domain'`, which *sets* every rule's profile. It now enables only the rules whose profile never includes Public, and leaves every profile unchanged. The groups are found by language-independent resource IDs (`@FirewallAPI.dll,-32752` / `-28502`), so it also works on non-English Windows; the status table uses the same IDs. |
| K2 | S2 | `Restore-RegBackup` (VALUE rows): a failed write or delete now reports **FAILED** and does **not** mark the backup as restored, so the original is never lost. |
| K3 | S2 | Take ownership: aborts **before** changing anything if `icacls /save` fails. If `takeown /d y` fails (the answer letter is translated on non-English Windows), it falls back to `icacls /setowner *S-1-5-32-544`. A failed `/reset` gives a warning. |
| K4 | S2 | Power settings (Sleep, Display, USB selective suspend) are read **without** matching English `powercfg` words: GUID lines and hex values only. |
| K5 | S2 | "Reset sign-in token cache" and "Rebuild tile database" show whether the service stopped. If it didn't (that needs admin), they abort with a clear message instead of claiming success. New `Get-WrongUserWarning` warns when the tool runs elevated as a different account than the signed-in user. |
| K6 | S2/S4 | Winsock catalog count is read from the registry; cmdkey targets come from lines containing `=`. Both work in every language. |
| K7 | S3 | Restore point: compares the count before and after (`Checkpoint-Computer` only *warns* within 24 h of the last one), so "created" is only claimed when it really was. |
| K8 | S3 | Full registry backup: success is judged by `reg save`'s exit code, and it's marked done only if both hives were saved, otherwise it's retried before the next fix. |
| K9 | S3 | KB removal: the wusa exit codes are corrected (0x240007 = not installed; 0x240006 = already installed). |
| K10 | S3 | Test access: `\\nas\public` is reduced to the host `nas`. |
| K11 | S3 | "Set Public→Private" and SMB Method 3 check each step (`-ErrorAction Stop`) instead of printing success unconditionally. |
| K12 | S3 | The WinHTTP proxy reset (single fix and FULL reset) backs up `WinHttpSettings` first (new `Backup-WinHttpProxy`), so a company proxy can be restored. |
| K13 | S3 | Windows Update reset: BITS jobs are cleared **before** the services stop (otherwise `Get-BitsTransfer` restarts BITS). Delivery Optimization (DoSvc) is stopped too. The BITS queue on Windows 10/11 (`qmgr.db` and edb logs) is renamed, not just `qmgr*.dat`. |
| K14 | S3 | Search status lists the real index files (`.edb` / `.db`) and honours a moved index (`DataDirectory`) through new `Get-SearchIndexDir`. The rebuild uses the same folder. |
| K15 | S3 | Restart Explorer waits up to 5 s for Windows to restart the shell, and **never** starts Explorer from an elevated tool (that would give an admin desktop). |
| K17 | S4 | `Win32_PnPSignedDriver` queries are filtered in WQL, about 4× faster in the review's measurement. |
| K18 | S4 | Store status queries `Get-AppxPackage` **once** instead of three times, and falls back to the current user's apps when not elevated, instead of three "Access denied" lines. |
| K21 | S4 | "Set Balanced" no longer triggers a full hive backup and restore point. It backs up only `ActivePowerScheme`. |
| K22 | S4 | Help text says "Reports folder" where files actually go there. "Re-register ALL apps" now lists each failed package with its reason plus a total, matching its help. The unreadable-backup warning is shown once, not after every fix. |
| W1 | S3 | (found in the windowed test) **Energy report:** `powercfg /energy` returns in under 1 s with **no report** on this Windows build. The fix now says so, instead of ending silently. |
| W2 | S3 | (windowed test) **KB removal:** wusa returned **exit code 87** for a not-installed KB, which used to show "Not removed. Try Settings…". It's now explained, using what Get-HotFix found. |
| W3 | S4 | Battery report: only says "Saved" if the file exists; otherwise it says the PC may have no battery. |

## WinSuperTool

| # | Sev | Change |
|---|---|---|
| S1 | S2 | AI request: an empty `.evtx` gives "(this event log contains no events)" instead of an exception. Each file is read in its own try/catch, so **one bad file no longer cancels the whole request**; it's listed as "not sent (reason)". |
| S2 | S2 | When an event log is too long, the **start** (header + newest events) is kept, not the end. |
| S3 | S2 | QR pairing: an overall 1.5 s deadline per connection, so a client sending one byte at a time can't hold the window. |
| S4 | S2 | Recovery window tools run in a **PowerShell console with single-quoted arguments** (`-EncodedCommand`) instead of `cmd /c … & pause`, so `& ^ % ( )` in paths can't break or inject commands. The console shows the exit code. |
| S5 | S2 | Dual boot on a running Windows: the second install's entry is found in the **loaded system store** first. The ESP no longer has to be mounted, which made every backup and change fail. |
| S6 | S2 | Log collection: closing the tool and switching tabs are refused while it runs (closing could unmount the source drive). Folder copies show progress every 25 files and keep the window responsive. |
| S7 | S3 | bcdboot and `bootrec /rebuildbcd` back up the BCD first, as the help promises. |
| S8 | S3 | Recovery tools without a console now show a result message with the exit code. |
| S9 | S3 | WinPE without Storage cmdlets: the mount memory is checked through diskpart instead of being dropped. |
| S10 | S3 | New `Get-DpPartLetter`: reads the drive letter from diskpart's `detail partition` **by column position**, with no English words. |
| S11 | S3 | Images: about 3.5 MB per image (it stays under a 5 MB limit even as base64) and **15 MB total** per request. |
| S12 | S3 | (in part) the AI request shows "Preparing <file>…" and keeps the window responsive between files. The Appx pre-flight and diskpart calls still block briefly. |
| S13 | S3 | QR pairing: the first rejected key ends the QR code, so the one-time pad is never reused. |
| S14 | S3 | `Resolve-BcdTarget` only scans fixed and removable drives (not network or optical). |
| S15 | S4 | A Gemini `MAX_TOKENS` cut-off is flagged. |
| S16 | S4 | A failed offline BCD restore always puts the file's hidden+system attributes back. |
| S17 | S4 | `Get-ImagePart` disposes every GDI object on every path. |
| S18 | S4 | `Copy-One` uses `[IO.File]::Copy` first (faster), and a failed fallback copy no longer leaves a partial file. BIG checks free space before copying gigabytes of dumps. |
| S19 | S4 | INFO counts only successful steps (systeminfo, hotfixes, packages, offline dism) and reports failures. |
| S20 | S4 | Crash events: "no events found" is told apart from real errors. |
| S21 | S4 | Version header, "-Tail N" help, and the backup-tool summary for offline stores are corrected. |
| R1 | S2 | Closing the tool while a repair console it started is still running **asks** before auto-unmounting (No is the default). |
| R2 | S2 | `Dismount-One` re-checks that the letter still belongs to the remembered partition. If another volume took it, the entry is forgotten and **nothing is unmounted**. |
| R7 | S3 | Unattend deploy: if backing up the existing answer file fails, it's **not** overwritten. |
| R15 | S4 | Safe Mode clone deletion reports clones that couldn't be deleted. |
| I1 | S2 | (found by the new unit tests) An **undecodable picture** (e.g. a broken `.png`) used to be sent to the API as-is, and the API rejects the whole request for that. It's now skipped with a note. |
| E1 | S2 | (found by the full log-generation run) `Export-Evt` reported **every** `wevtutil` failure as "skipped (channel missing/empty)" and never counted it. A real failure (bad path, access denied, disk full) left the Event Viewer folder **empty with "0 failed"**. Now exit code 15007 (channel does not exist, language-independent) is a skip, and anything else is **FAILED** with the reason, and counted. |
| B1 | S3 | (log-generation run) The AI tab read a binary `.etl` trace as **text**: 144,582 characters of garbage would have been sent. Known binary extensions (`.etl .dmp .hiv .dat .cab .zip .exe .dll .sys .db .edb …`) are now skipped, and `U+FFFD` replacement characters count toward the binary check. |
| P1 | S3 | (log-generation run; a regression from my own S18 check) The BIG free-space check ran `Get-ChildItem <missing MEMORY.DMP> -Recurse`, which PowerShell treats as a *filter* and so searched **all of C:\Windows**: 53.8 s → now 0.09 s (only existing paths, `-LiteralPath`). |
| AI | — | **Claude request:** `max_tokens` 4096 → **16000**, because on Sonnet 5.5 adaptive thinking is on by default and counts toward the limit; 16000 is the recommended ceiling for non-streaming requests. Added the **server-side refusal fallback** (`"fallbacks":"default"` + beta header `server-side-fallback-2026-07-01`). A `refusal` stop reason is shown with its category, and an empty answer shows the stop reason. Request timeout is 600 s. |

## Not fixed in V1.7 (and why)
- **K16 / S12 / R10:** long work still runs on the UI thread in a few places (reg save, Appx scans, diskpart calls). Moving it to background runspaces would need a larger restructure. Done so far: status text plus `DoEvents` where it was cheap (AI request, log collection).
- **K19 / K20:** repeated `Get-Printer` and `Get-HotFix` calls in status. Minor (about 1–2 s), left as they are.
- **R3–R6, R11–R14, R16–R18, A1–A24:** these are in WinRepairTool and the standalone scripts, which are waiting for your retire-or-port decision.
- **Unconfirmed (couldn't be tested here):**
  - a localized Unattend group name;
  - "password never expires" for standard users.
