## What is new (Recovery tab)

### Pass / fail summary

The new **Show a pass / fail summary when it ends** checkbox is on by default. When a tool finishes, a window shows two things:

1. **Did the task run to the end?** One of:
   - **TASK PASSED**: it ran to the end;
   - **TASK FAILED**: it did not complete;
   - **TASK DID NOT RUN**: action is needed, for example a restart is pending.
2. **What it found**, in plain words, with the tool's **own result message** quoted word for word.

| Tool | Possible results |
|---|---|
| sfc /verifyonly (new) | NO CORRUPTION DETECTED, or CORRUPTION DETECTED (scan only, nothing repaired) |
| sfc /scannow | NO CORRUPTION DETECTED; CORRUPTION DETECTED - FIX WORKED; CORRUPTION DETECTED - FIX DID NOT WORK for some files; NOT CHECKED (repair pending, service would not start, could not perform the operation) |
| DISM check health / scan health (new) | NO CORRUPTION DETECTED; CORRUPTION DETECTED - it can be repaired; CORRUPTION DETECTED - it can NOT be repaired; FAILED with the DISM error code |
| DISM restore health | CORRUPTION DETECTED - FIX WORKED; NO CORRUPTION LEFT; FIX DID NOT WORK (for example 0x800f081f, source files not found); FAILED with the error code |
| chkdsk /scan | NO PROBLEMS FOUND; PROBLEMS DETECTED; NOT CHECKED |
| chkdsk /f | PROBLEMS FOUND - FIX WORKED; NO PROBLEMS FOUND; SCHEDULED for the next restart; NOT RUN; FIX DID NOT WORK |
| bcdboot, bootrec | FIX WORKED or FIX DID NOT WORK; for /scanos, how many installs were found |
| Driver list / inject / remove | COMPLETED, AT LEAST ONE DRIVER FAILED, NO DRIVERS WERE ADDED |

Each summary also shows:
- a **next step**;
- the command;
- the run time;
- the exit code (also in hex for DISM codes);
- a **Show full output** button.

The full output is saved in `WinSuperTool-Data\Task-Results`, and the result is written to the activity log.

The BCD and boot-menu tools already show their own result, so the checkbox is greyed out for them.

### Monitor this task's logs

When this is ticked, the live log windows for the selected tool open as the task starts. They use the same windows as the Live Monitor tab.

| Tool | Logs watched live |
|---|---|
| sfc (both) | `CBS.log`, `[SR]` lines only |
| DISM check health | `dism.log` |
| DISM scan health, restore health | `dism.log`, `CBS.log` |
| Driver tools | `dism.log`, `setupapi.dev.log` |

The checkbox is greyed out for tools that write no log, such as chkdsk, bcdboot and bootrec.

### New tools

- **System file check, scan only (sfc /verifyonly)**: checks for corruption without repairing.
- **DISM: check health (quick, read-only)**: `/cleanup-image /checkhealth`.
- **DISM: scan health (full scan, read-only)**: `/cleanup-image /scanhealth`.
- "System file check (sfc)" is renamed **System file check and repair (sfc /scannow)**.

All three switch to `/online` on the running Windows, and use `/image:` or `/offwindir` for an offline install, like the existing tools.

## How it works

When the summary is on, the task's console window works as before:
- it runs the exact same command;
- progress bars and Y/N prompts, such as chkdsk's "schedule at next restart?", work normally.

The difference is what happens when the command ends:
1. The window **reads back what the command printed** from its own console screen buffer.
2. It saves that to the result file **before** "Press Enter to close".
3. WinSuperTool's timer picks up the file and opens the summary.

**Why the window looks different:** with the summary on, the task opens in a classic console window instead of Windows Terminal. A classic window keeps the whole output in its buffer, so all of it can be read back. With the summary off, nothing changes from 1.8.

Reading the screen avoids the problems of redirecting output. For example, sfc writes UTF-16 when redirected, which garbles the text.

**Matching the messages:** sfc and chkdsk wrap their own messages at about 70 characters. The matcher therefore joins each paragraph and matches whole sentences, and the summary quotes the full sentence.

**Other languages:** the result messages are matched in **English**. On another display language nothing matches, so the summary uses the exit code and says so.

**Closed windows:** if you close the task window before it finishes, you get a note that there is no summary.
